# Asia Unhurried / 亚洲不疾不徐

Calm Asia travel guide (excluding mainland China; includes Hong Kong, Macau, and Taiwan).

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

Source files for pages, map data, and copy will be written from the project dump. Do not invent shops, visa notes, prices, or ratings.
